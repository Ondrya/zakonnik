# Законник

Рабочее пространство юридических инструментов. Каждый инструмент — отдельный проект в `projects/`.

Лицензия: [MIT](LICENSE).

## Проекты

| Проект | Что делает | Как запустить |
|--------|------------|----------------|
| [`kadastr`](projects/kadastr/README.md) | Разбор кадастровых номеров по ПКК/НСПД с подсветкой проблем и справочником терминов | `python projects/kadastr/run.py 50:14:0000000:156789` |

## Структура

```
Законник/
  projects/           # проекты (каждый самодостаточен)
    kadastr/
  output/             # (legacy) старые отчёты, новые пишутся в projects/<имя>/output
```

Новые проекты добавляются папкой в `projects/` без изменения соседей.
